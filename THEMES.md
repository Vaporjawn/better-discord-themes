# Theme Catalog

Every theme below is vendored under [`themes/`](themes/) with its upstream `LICENSE` kept beside it, grouped as `themes/<owner>/<repo>/`. Copy any `*.theme.css` file into your BetterDiscord themes folder. Authors, versions and source links come from each theme's own header. Many themes `@import` their stylesheet from the author's GitHub Pages or raw GitHub, so they need internet access and follow upstream updates.

**814 themes from 215 repositories**, sorted by upstream stars. Only repositories with an open-source license are included.

The original hand-picked collection (the `*.theme.css` files in the repo root and `New Themes/`) is listed in the README and `themes.json`. The repo's own validation scripts only check those files, not `themes/`.
